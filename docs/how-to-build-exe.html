Find the Workflow & Click "Run workflow"

On the Actions page you will see the workflow called "Build Windows Installer (.exe)" in the left sidebar.

STEP 4 OF 7

Confirm & Start the Build

A small dropdown panel appears under the "Run workflow" button. You do not need to change anything — just click the green "Run workflow" confirmation button.

  • 🌿Branch: main (already selected)
  • 🏷️Version: v1.0.0 (default — leave it)
  • ✅Click the green button to start building
⏱️ How long? The build takes about 15–25 minutes. GitHub builds on a real Windows machine so this is normal.

STEP 5 OF 7

Watch the Build Progress

After clicking Run workflow, a new entry appears in the list. Click it to see the live progress. Each step runs in order on a real Windows server.

  • 🔄A spinning circle = step is running
  • ✅A green tick = step completed
  • ⏱️Total time: ~15–25 minutes
  • 🔔GitHub can email you when it finishes
📌 You don't need to stay on this page. Close the browser tab — the build keeps running on GitHub's servers.

Go to the "Releases" Tab & Download

When the build finishes (all ticks green ✅), go back to the main repository page and click the 📦 Releases tab — or look for the Releases section on the right side of the Code page.

  • 🏷️Find the release labelled v1.0.0

  • ⬇️The file downloads to your computer
📁 File size The installer is typically 60–90 MB. Save it anywhere on your computer.

STEP 7 OF 7

Install & Launch the Application

Double-click the downloaded UTM-Thesis-Converter-Setup.exe file. The Windows installer wizard opens. Follow the on-screen steps — it takes about 30 seconds.

  • 🖱️Double-click the .exe in your Downloads folder
  • 📂Choose install location (or keep default)
  • ✅Click "Next → Next → Install → Finish"
  • 🚀Application opens — ready to convert!
🛡️ Windows SmartScreen? If Windows shows "Unknown publisher" warning, click More info → Run anyway. This is normal for new software.
